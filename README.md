# Arizona Rules AI

Небольшой закрытый веб-сайт для поиска и вопросов по правилам игрового проекта Arizona RP.

**Как работает:** администратор загружает правила → сервер автоматически распределяет документы по категориям и разбивает текст на небольшие части → SQLite FTS5 создаёт поисковый индекс → чат находит релевантные части → Gemini 3.8 Flash (при наличии API-ключа) формулирует ответ **только по найденным материалам** и указывает источники `[1]`, `[2]`.

## Возможности

- Чат на русском языке и ссылки на загруженные первоисточники.
- Импорт нескольких TXT / MD / PDF / DOCX / HTML документов за раз.
- Импорт публичных тем по `https://forum.arizona-rp.com/...` (если форум разрешает автоматический доступ).
- Ручная вставка текста со ссылкой на источник.
- Автоматическая категоризация (по ключевым словам в заголовке и тексте), ручной выбор категории.
- Локальная SQLite-база с поисковым индексом, защита от дубликатов, удаление устаревших документов.
- Вход по паролю для частного сайта.
- Без Gemini API работает обычный поиск по фрагментам, **это не полноценный ИИ-ответ**.

## Быстрый запуск на ПК

Требуется Python 3.11+.

```bash
python -m venv .venv
# Windows PowerShell:
.venv\Scripts\Activate.ps1
# macOS / Linux:
# source .venv/bin/activate
pip install -r requirements.txt
```

Создай `.env` из `.env.example`, впиши свои безопасные `APP_PASSWORD`, `APP_SECRET` и `GEMINI_API_KEY`. Для запуска с переменными из `.env`:

```bash
uvicorn app.main:app --reload --env-file .env
```

Если задаёшь `APP_PASSWORD`, `APP_SECRET` и `GEMINI_API_KEY` непосредственно в переменных окружения ОС:

```bash
uvicorn app.main:app --reload
```

Открой `http://127.0.0.1:8000`. На Windows также можно запустить `start_windows.bat`: при первом запуске откроется `.env` для настройки.

**Настройки:**

| Переменная | Назначение |
| --- | --- |
| `APP_PASSWORD` | Пароль для входа; обязательно при публичном размещении |
| `APP_SECRET` | Длинная случайная строка для подписи сессий; обязательно на продакшене |
| `APP_ENV` | `production` на хостинге, иначе `development` |
| `GEMINI_API_KEY` | API-ключ Google Gemini; **хранится только на сервере** |
| `GEMINI_MODEL` | `gemini-3.8-flash` по умолчанию |
| `DATA_DIR` | Папка с постоянной SQLite-базой |

Если пароль не установлен, сайт разрешает доступ только с локального компьютера (localhost) и **не подходит для публичной сети**.

## Хостинг Render

`render.yaml` настроен на **бесплатный тариф Free без постоянного диска**. SQLite-база с загруженными правилами теряется при перезапуске, обновлении или засыпании сервиса. Сохраняй исходные документы для повторного импорта. После 15 минут без запросов сервис засыпает; первый запуск может занять около минуты.

1. Создай новый **приватный** репозиторий GitHub и загрузи содержимое этого проекта.
2. В Render выбери **New → Blueprint** и подключи репозиторий.
3. Render использует `render.yaml`. Введи значения `APP_PASSWORD` и `GEMINI_API_KEY` в безопасных полях Render; `APP_SECRET` генерируется автоматически.
4. Проверь тариф Free и статус развертывания. Постоянный диск не используется.
5. Открой сайт, войди по паролю, импортируй правила.

**Не добавляй реальные API-ключи в GitHub.** Используй только переменные окружения на Render.

## Особенности

- Форум может блокировать ботов, переадресовывать запросы или требовать авторизацию. Сайт не обходит блокировки: используй ручную вставку текста или загруженные документы.
- Встроенный PDF-парсер извлекает только текстовый слой. Сканированные изображения страниц без текста надо предварительно перевести в текст разрешённым способом.
- Индексируемые тексты должны быть доступны тебе для использования. Сохраняй ссылки и проверяй авторские права и правила форума.
- ИИ может ошибаться. Сверяй ответы с первоисточниками, особенно если правила сервера обновились.
- Автокатегоризация в MVP основана на ключевых словах, это **не** ИИ-классификация. Полнотекстовый поиск использует русские префиксы, но не полноценные семантические эмбеддинги.
- Сайт не парсит всё дерево форумов автоматически: импорт происходит по введённым ссылкам или загруженным файлам.
- Из соображений безопасности импорт внешних страниц ограничен доменом `forum.arizona-rp.com`, HTTPS и объёмом 3 МБ.

## Структура

```text

app/storage.py    SQLite FTS5, категоризация и поиск
app/ingest.py     Импорт файлов, текстов и страниц форума
app/ai.py         Ответы Gemini по контексту
app/static/       Интерфейс HTML/CSS/JS
tests/            Автотесты
render.yaml       Конфигурация Render с постоянным диском
```
